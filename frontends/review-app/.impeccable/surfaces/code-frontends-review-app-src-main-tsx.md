# Sidequest library and review flows

Scope: discovery, game details, review editor and player profile. Mode: Experience for browsing, Operate for writing. Approved workspace comp (retained outside this Git repository): `.impeccable/mocks/sidequest-b.png`.

## Direction contract

THESIS: A console-like collection makes game artwork the way into player reviews. Preserve the familiar browsing task while replacing the previous broad-banner composition.

OWN-WORLD: Charcoal ground, citron actions, bold condensed game headings and precise sans-serif controls. Real cover art supplies color and subject; quiet chrome supports it.

STORY: Browse the covers, select a game, read what players think, then sign in when ready to contribute. Profile and source links remain available.

FIRST VIEWPORT: Compact navigation and search/filter tools above four large cover panels. The selected cover lifts slightly. Game title, description, platform labels and Read reviews sit beneath. The collection begins within the first desktop viewport. Mobile uses a native horizontal gallery and a two-column catalog.

FORM: User-selected Collection concept B, pinned over alternatives; reference seed:37f939271adaa6b2. Use the approved real publisher artwork and actual review data; ignore the generated bookmark and unsupported game examples in the comp.

FINISH: unreviewed and undocumented is unfinished; the builder never reviews its own work.

## Copy and motion

Sign in and My profile are the primary account language. Explain wallet approval only at the step that needs it. View source is secondary. Motion communicates gallery selection and button feedback, with short gated hover transitions and reduced-motion alternatives.
